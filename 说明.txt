RouterSight 路由视界 v1.0 —— iStoreOS 路由器监控桌面小组件
（基于 NetSight v2.1.1 修改，原作者 RtrBug / 酷友社论坛；修改：知影）

════════════════════════════════════════
一、怎么用
════════════════════════════════════════
1. 双击  RouterSight\RouterSight.exe      ← 推荐，启动快
   或者  RouterSight_单文件版.exe        ← 单个文件，首次启动稍慢
2. 启动后卡片默认出现在屏幕右上角；位置/大小会自动记住
3. 托盘图标右键 → 设置，可改路由器地址、账号、密码、网卡、主题等
4. 想移动卡片：直接按住卡片拖动（新版不再需要「解锁」）

不需要在路由器上装 NetData 系统监控 —— 数据是 SSH 直读路由器 /proc 拿的。

════════════════════════════════════════
二、和原版的区别
════════════════════════════════════════
1. 去掉 NetData 依赖
   原来走 http://<路由器>:19999/api/v1/allmetrics（Netdata HTTP 接口），
   现在改成 SSH 登录路由器读 /proc/stat、/proc/meminfo、/proc/net/dev、
   /proc/diskstats、/proc/net/{tcp,udp}，不需要在路由器上装任何东西。

2. 修好局域网传输速度翻倍
   原来把 Netdata「所有网卡」的 InOctets + OutOctets 相加。一次 WAN 下载会
   同时记在 eth0.rx、eth1.tx、br-lan.tx 上，所以读数约为真实值的 3 倍；
   局域网互传则约为 2 倍。
   实测证据：单向 500MB 拉流时，eth1 上行 464549 kb/s，而原口径合计 928501 kb/s
   = 恰好 2.0 倍。
   现在只统计你在设置里选中的那一张网卡，而且下载/上传分开显示，不跨网卡相加。

3. 卡片（6 张，3 行 × 2 列）
   CPU 使用率 / 内存使用
   磁盘 I/O  / 下载速度（MB/s，青色）
   上传速度（MB/s，紫色） / TCP-UDP 连接（TCP/UDP 分开计数）

4. 图标和界面重做
   新图标；设置窗口统一主题；明亮主题改用 Windows 11 (WinUI) 规范配色
   （底 #F3F3F3、卡片白、边框 #E5E5E5、主色 #0067C0），字体优先
   Segoe UI Variable / Segoe UI / 微软雅黑；托盘菜单也跟着主题变。

5. 新功能：靠边隐藏
   把卡片拖到屏幕左/右/上/下边缘（14 像素内）松手，就会停靠在那边；
   鼠标离开 0.5 秒后自动收起、只在边缘留 4 像素；鼠标碰到那 4 像素会自动滑出。
   多显示器按「光标所在屏幕」判断，并且用工作区计算，不会盖住任务栏。
   开关：设置 → 显示设置 → 窗口行为 → 靠边隐藏。

6. 新功能：鼠标穿透
   开启后卡片不挡鼠标，点击直接穿透到下面的窗口（适合把卡片贴在桌面上看数据）。
   穿透状态下卡片不能右键、也不能拖动，只能从托盘菜单关掉 —— 这是设计如此。
   开关：托盘右键 → 鼠标穿透（前面有 ✓ 表示已开启）。

7. 去掉了「显示/隐藏」和「锁定/解锁」两个托盘菜单项
   卡片始终可见、始终可拖动，这两个状态不再需要。

════════════════════════════════════════
三、托盘菜单
════════════════════════════════════════
鼠标穿透 / 置顶 / 开机启动 / 设置 / 退出
（左键单击托盘图标：把靠边隐藏的卡片叫出来）

════════════════════════════════════════
四、配置与排错
════════════════════════════════════════
· 配置文件：和 exe 同目录的 RouterSight_config.ini
  如果那个目录里只有旧的 NetSight_config.ini，首次启动会自动复制一份过来。
· 密码以明文保存在 ini 里，请不要把这个目录共享出去。
· 命令行自检：RouterSight.exe --selftest
  会在同目录生成 RouterSight_selftest.txt，里面含连接结果和各路指标，
  连不上路由器时先看这个文件。
· 配置文件缺的新开关（edge_hide / click_through 等）启动时会自动按默认值补齐，
  不会覆盖你已保存的其他设置。

════════════════════════════════════════
五、注意
════════════════════════════════════════
· 你的路由器在局域网上开放了 80/443/3000/8888/9090/7681 端口，
  其中 7681 是网页终端（ttyd）。建议确认这些服务不需要对公网开放。
· 本程序只在局域网内 SSH 路由器，不做任何外发连接（除 favicon 缓存外不联网）。
