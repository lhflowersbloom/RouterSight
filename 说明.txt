RouterSight 路由视界 v1.0 —— iStoreOS 路由器监控桌面组件
（基于 NetSight v2.1.1 修改，原作者 RtrBug / 酷友社论坛；修改：知影）

════════════════════════════════════════
一、使用方法
════════════════════════════════════════
1. 双击  RouterSight\RouterSight.exe      ← 推荐，启动较快
   或    RouterSight_单文件版.exe        ← 单文件形式，首次启动稍慢
2. 启动后卡片默认出现在屏幕右上角；位置与尺寸会自动记住
3. 托盘图标右键 → 设置，可修改路由器地址、账号、密码、网卡、主题等
4. 移动卡片：直接按住卡片拖动即可（本版已移除「解锁」步骤）

无需在路由器上安装 NetData 系统监控 —— 数据通过 SSH 直读路由器 /proc 获取。

════════════════════════════════════════
二、与原版的差异
════════════════════════════════════════
1. 移除 NetData 依赖
   原版通过 http://<路由器>:19999/api/v1/allmetrics（Netdata HTTP 接口）取数；
   现改为 SSH 登录路由器读取 /proc/stat、/proc/meminfo、/proc/net/dev、
   /proc/diskstats、/proc/net/{tcp,udp}，路由器端无需安装任何组件。

2. 修复局域网传输速率翻倍
   原版将 Netdata「所有网卡」的 InOctets + OutOctets 相加。一次 WAN 下载会
   同时计入 eth0.rx、eth1.tx、br-lan.tx，故读数约为真实值的 3 倍；
   局域网互传则约为 2 倍。
   实测证据：单向拉取 500MB 数据时，eth1 上行 464549 kb/s，原口径合计 928501 kb/s
   = 恰好 2.0 倍。
   现仅统计设置中选定的单个网卡，且下载 / 上传分别显示，不跨网卡相加。

3. 卡片（6 张，3 行 × 2 列）
   CPU 使用率 / 内存使用
   磁盘 I/O  / 下载速率（MB/s，青色）
   上传速率（MB/s，紫色） / TCP-UDP 连接数（TCP/UDP 分别计数）

4. 图标与界面重做
   全新图标；设置窗口统一主题；明亮主题改用 Windows 11 (WinUI) 规范配色
   （底色 #F3F3F3、卡片 #FFFFFF、边框 #E5E5E5、主色 #0067C0），字体依次为
   Segoe UI Variable / Segoe UI / 微软雅黑；托盘菜单同步跟随主题。

5. 新增功能：靠边隐藏
   将卡片拖至屏幕左 / 右 / 上 / 下边缘（14 像素以内）后松手，即停靠于该边缘；
   鼠标移开 0.5 秒后自动收起，仅在屏幕内保留 4 像素；鼠标移至该 4 像素即自动滑出。
   多显示器按「光标所在屏幕」判定，并以工作区计算，不遮挡任务栏。
   开关位置：设置 → 显示设置 → 窗口行为 → 靠边隐藏。

6. 新增功能：鼠标穿透
   启用后卡片不拦截鼠标，点击直接穿透至下层窗口（适合将其置于桌面长期查看数据）。
   穿透状态下卡片无法右键、无法拖动，仅可从托盘菜单关闭 —— 此为设计行为。
   开关位置：托盘右键 → 鼠标穿透（前方显示 ✓ 表示已启用）。

7. 移除「显示/隐藏」与「锁定/解锁」两个托盘菜单项
   卡片始终可见、始终可拖动，这两个状态已无必要。

8. 新增功能：密码框可见性切换
   设置窗口的密码默认以掩码显示，点击右侧眼睛图标即可临时查看明文，便于核对输入；
   再次点击恢复掩码。该开关仅影响显示，密码仍按原样保存在配置文件中。

9. 修复：连接失败不再占满路由器的 SSH 会话
   路由器（dropbear）能同时接受的未认证 SSH 连接数很小。旧版在连接失败时不释放
   套接字，反复重试会把配额占满，之后即使密码正确也会报
   「Error reading SSH protocol banner」。现改为失败时立即关闭连接，并在连续失败时
   按 2 / 4 / 8 / 16 / 30 秒退避重试（成功即恢复原刷新频率）；该错误的提示也已改为
   中文说明。

════════════════════════════════════════
四、配置与排错
════════════════════════════════════════
· 配置文件：与 exe 同目录的 RouterSight_config.ini
  若该目录中仅有旧的 NetSight_config.ini，首次启动会自动复制一份。
· 密码以明文保存在 ini 中，请勿共享该目录。
· 命令行自检：RouterSight.exe --selftest
  将在同目录生成 RouterSight_selftest.txt，内含连接结果与各项指标；
  无法连接路由器时请先查看该文件。
· 若提示「路由器未响应 SSH 握手（连接数已满或被限流）」，等待约 30 秒即可恢复；
  本版已修复导致该现象的套接字泄漏，正常情况下不会再出现。
· 配置文件缺失的新开关（edge_hide / click_through 等）在启动时按默认值补齐，
  不会覆盖已保存的其他设置。

════════════════════════════════════════
五、注意事项
════════════════════════════════════════
· 该路由器已在局域网内开放 80/443/3000/8888/9090/7681 端口，
  其中 7681 为网页终端（ttyd）。建议确认这些服务无需对公网开放。
· 本程序仅在局域网内通过 SSH 访问路由器，不进行任何外发连接（除 favicon 缓存外不联网）。

六、构建信息
════════════════════════════════════════
源文件   ：RouterSight.py + routersight_router.py
打包     ：python build.py（PyInstaller 6.22.3，Python 3.12）
界面预览 ：ui_preview.py（离屏渲染设置窗口）、render_widget.py（离屏渲染卡片）
功能自测 ：smoke_test.py（取数 + 各卡片文本）、edge_test.py（靠边隐藏几何 + 鼠标穿透样式）、
           leak_test.py（失败连接不残留套接字）、recover_test.py（错误密码后仍可连接）
依赖     ：PyQt5 5.15.11、paramiko、cryptography
